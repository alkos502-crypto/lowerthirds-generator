# Lower Thirds Generator — CEP-плагин для Premiere Pro

Плагин автоматически раскладывает титры нижней трети на таймлайн из CSV-файла
и подставляет текст внутрь выбранного **MOGRT**-шаблона.

- Панель открывается в Premiere Pro: **Окно → Расширения → Lower Thirds Generator**.
- Выбираете CSV → MOGRT → сопоставляете поля → «Создать нижние трети».
- Титры выкладываются на выбранный видео-трек, стык в стык, от точки воспроизведения.

---

## Установка (dev-режим, без подписи)

Скопируйте папку `LowerThirds` целиком во встроенную папку расширений CEP:

- **macOS:**
  `~/Library/Application Support/Adobe/CEP/extensions/LowerThirds`
- **Windows:**
  `C:\Users\<ваш_пользователь>\AppData\Roaming\Adobe\CEP\extensions\LowerThirds`

Если папки `extensions` нет — создайте её.

После копирования **полностью перезапустите Premiere Pro** (Cmd/Ctrl+Q и заново).
Панель появится в меню **Окно → Расширения**.

> Начиная с Premiere 2020+ пользовательские несжатые расширения грузятся из этой
> папки без подписи. Если панель не появилась — проверьте, что активен Debug-режим
> (см. ниже), или что путь установки именно такой.

### Если панель не появляется (Debug-режим)
1. Удалите файл `~/.local/share/adobedebug` (если есть).
2. В ЦС: **Особые → Выпуск → CSXS/CEP** → в поле Debug Mode впишите:
   Windows `C:\Users\<пользователь>\AppData\Roaming\Adobe\CSXS\4.0\PlayerDebugMode` = `1`
   macOS выполните в Терминале:
   ```
   defaults write com.adobe.CSXS.11 PlayerDebugMode 1
   ```
3. Перезапустите Premiere.

## Требования к работе

1. **MOGRT-шаблон должен быть создан в After Effects** и иметь хотя бы один
   динамический параметр (текст), вынесенный в Essential Graphics
   (коллекция «Основные свойства»). Только такие тексты плагин может менять
   программно. Шаблоны, созданные прямо в Premiere, текст скриптом не меняются.
2. CSV должен быть **UTF-8** (без BOM). Разделитель определяется автоматически
   (запятая, точка с запятой, таб). Первая строка — заголовки колонок.
3. Имена полей: мультивыбор в шаге 3 автоматически подставит параметр, если его
   имя совпадает с заголовком колонки CSV. Если имя параметра шаблона иное —
   выберите его вручную из выпадающего списка (или впишите имя вручную, если
   перечислить поля шаблона не удалось — поля можно посмотреть в Premiere:
   выделить MOGRT на таймлайне → Essential Graphics → вкладка «Редактировать»).

## Порядок работы

1. **Шаг 1:** «Выбрать CSV-файл» → показывается число строк и колонок.
2. **Шаг 2:** выберите видео-трек, затем «Считать поля шаблона». Плагин положит образец
   шаблона на таймлайн и прочитает имена его параметров.
3. **Шаг 3:** отметьте, какая колонка CSV соответствует какому параметру шаблона.
4. Кнопка **«Создать нижние трети»** — раскладывает все строки стык в стык
   (по внутренней длительности шаблона) на выбранный трек, начиная с точки
   воспроизведения, и подставляет текст.

## Путь к MOGRT — файл config.json

Шаблон задаётся в файле **`config.json`**, который лежит рядом с панелью
(в той же папке `LowerThirds/`). Чтобы сменить шаблон — отредактируйте путь там
и **переоткройте панель** (или перезапустите Premiere). Диалог выбора файла не используется.

```json
{
  "mogrtPath": "/Volumes/MEDIASTORE/МОНТАЖ 2026/ОФОРМЛЕНИЕ/MC TITLE Russia1 mac.mogrt"
}
```

Примечания:
- Файл должен быть в кодировке **UTF-8**.
- Пробелы и кириллица в пути — ок, экранирование не нужно.
- **Windows:** пути со слешами `\` надо экранировать в JSON двойным `\\`, например
  `"mogrtPath": "C:\\Users\\admin\\Desktop\\MC TITLE.mogrt"`.
- Если `config.json` отсутствует или поле пустое — плагин берёт фолбэк-путь,
  зашитый в `host/main.jsx` (`DEFAULT_MOGRT_PATH`).

## Как изменить длительность каждого титра

Плагин использует внутреннюю длительность MOGRT. Чтобы каждый титр был короче/длиннее:
1. Создайте титры.
2. Отметьте их на таймлайне.
3. **Клип → Скорость/Длительность** — задайте длину, галочка «Риппл-редактирование»
   или сдвигайте границы вручную (Alt+перетаскивание правой кромки).

## Структура

```
LowerThirds/
├── CSXS/manifest.xml   # описание расширения для Premiere
├── index.html          # интерфейс панели
├── config.json         # путь к MOGRT-шаблону (редактируемый)
├── css/style.css
├── js/index.js         # логика панели (общение с ExtendScript)
├── host/main.jsx       # хост-скрипт ExtendScript (импорт MOGRT, раскладка, текст)
└── sample/sample.csv   # пример данных
```

## Ограничения и примечания
- Изменение текста внутри MOGRT работает через `getMGTComponent()` и доступно
  только для шаблонов, созданных в After Effects.
- Нумерация треков: в списке и в итоговом логе V1 — нижний трек. Индекс трека
  передаётся в `importMGT` напрямую (0 = V1). Если титры попали не на тот трек —
  выберите другой номер в шаге 2.
- Панель работает с **активной последовательностью** текущего проекта.
